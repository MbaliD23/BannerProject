# Dashboard layout reference

The dashboard follows the supplied homepage references without copying either brand: deep teal surfaces echo LuckyFish, while purple accenting recalls Hollywoodbets. This makes comparison feel native to the subject while keeping Banner Analytics visually independent.

## Overview

- KPI row: captured banners, active promotions, monitored websites, collection success.
- Promotion frequency area chart.
- Leading category chart.
- Recent banner-change table.

## Banner gallery

- Three-column responsive card grid.
- Captured screenshot or branded fallback art.
- Source, date, headline, categories, description, OCR detail, position, and prize value.
- Global search, sorting, website, date, category, keyword, and prize filters.

## Trend analytics

- Category trend lines.
- Monthly website counts.
- Recurring keyword chart.
- Advertised provider/game ranking.

## Competitor comparison

- Side-by-side category distribution.
- Prize value box plot.
- Strategic signal comparison for app, bonus, and jackpot activity.
- Summary table with total, new, active, and highest prize metrics.

## Insights and exports

- Deterministic, data-derived insight cards.
- Filter-aware CSV and Excel downloads.
- Audit table of included rows.

## Operations

- Schedule/timezone/site configuration.
- Recent run outcomes and errors.
- Explicit demo-mode/offline status.
